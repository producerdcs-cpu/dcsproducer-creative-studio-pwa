# DcsProducer® Creative Studio — PWA (Fase 1)

Scaffold do núcleo pessoal instalável sob governança AEGIS.

## Stack
- React 18 + Vite + TypeScript
- Tailwind CSS (cores oficiais da brand)
- vite-plugin-pwa (manifest + service worker)

## Como rodar local
```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy Vercel (HTTPS + instalar no celular)

1. Abra https://vercel.com/new no celular ou PC
2. Importe o repo `producerdcs-cpu/dcsproducer-creative-studio-pwa`
3. Framework: **Vite** · Build: `npm run build` · Output: `dist`
4. Deploy → copie a URL `https://….vercel.app`
5. No **Chrome Android**, abra a URL → menu **⋮** → **Instalar app** / **Adicionar à tela inicial**
